# Changelog

## 0.1.0-dev – initial scaffold (2026-09-19)

- Native Kotlin/Jetpack Compose Android project.
- Manual multi-box persistence with health validation.
- Local and Spotify transport/volume control.
- TTS via `/api/speak`.
- Compact battery/Wi-Fi and on-demand Bluetooth status.
- LAN-only endpoint and DNS guards for the current HTTP API.
- Future NSD discovery scaffold for `_mupibox._tcp.`.
- API fixtures/unit tests, CI, LXC bootstrap and Claude Code project guidance.
- MuPiBox-NG explicitly remains read-only from this repository.
